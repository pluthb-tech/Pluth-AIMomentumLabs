# Golf Achievement OS — Start Here

Built for Brad Pluth and Golf Achievement Academy from your uploaded Build Room OS.

1. Open index.html in a browser for the local dashboard. It works without installation or internet.
2. Read BUILDROOM_BUSINESS_FILE.md. It is prefilled, with sources and proposals separated; it remains provisional.
3. Validate the signature offer using the prompt in GOLF_ACHIEVEMENT_30_DAY_PLAN.md.

## Use with your AI tool

Claude Code: open this folder as your project, then start Claude. The .claude/skills folder contains the customized skills.
Codex: open this folder as your project. The .codex/skills folder contains the customized skills; discovery varies by client/version. If they are not listed, read the matching skills/<skill-name>/SKILL.md directly or install through your client's supported flow.
Cowork/claude.ai: upload the appropriate cowork/*.skill package using your client's skill-upload interface. Attach BUILDROOM_BUSINESS_FILE.md and SOURCE_REGISTER.md. Each package includes Golf Achievement context, but your latest business file supplies current facts.

The existing optional installers are retained as original utilities. They can overwrite same-named globally installed buildroom skills. Review them before use. No installer was run and nothing was installed into your home directory.

## Included

26 customized skills in readable, Claude, Codex, and Cowork versions; branded browser tools; local dashboard; provisional business file; messaging and offer brief; website copy; scorecard lead magnet; funnel/email starter; coaching SOPs; sales script; content plan; 30-day plan; blank metrics and pipeline CSVs.

Browser checklist/notes are stored locally when storage is available and exportable as JSON. The dashboard is a planning tool: it does not connect to either website, a CRM, payments, booking, or golfer accounts. The Business File Viewer embeds the initial draft; load the latest Markdown file to see later edits.

Source toolkit credit: Build Room / AI Momentum Labs. Golf Achievement customization preserves the generic curriculum and adds explicit business context. See CUSTOMIZATION_MANIFEST.md for changes and validation.
